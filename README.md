# K-means and E-means in C++

A C++17 implementation of the **K-means clustering algorithm**, developed from scratch as a learning project.

The project aims to provide a general-purpose implementation of K-means for numerical datasets, with support for CSV input, clustering evaluation, and performance benchmarking.

A future extension will implement **E-means**, allowing comparisons between the two algorithms in terms of computational efficiency and clustering performance.

## Status

Early development — project structure and CMake build system initialized.
